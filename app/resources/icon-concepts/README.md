# Propuestas de icono para TermoZona

- **A — Dial:** aro de temperatura del azul al naranja, con casa y llama en el centro; comunica control térmico de forma inmediata.
- **B — Casa radiante:** glifo de casa sólida con tres corrientes de calor y ondas de suelo; enfatiza el hogar y la calefacción por zonas.
- **C — Equilibrio:** gota fría y llama cálida integradas en una silueta; la opción más sintética y distintiva.

**Recomendación: A.** El dial parece una app de termostato incluso a 48 px y separa mejor el control de temperatura del icono actual; la casa central mantiene el contexto doméstico.
